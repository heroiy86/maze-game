# めいろゲーム

シンプルなめいろゲームです。タイムトライアル形式で、クリアまでの時間を競います。

## 遊び方

1.  **ゲームスタート**: 「ゲームスタート！」ボタンを押すとタイマーが開始し、迷路が表示されます。
2.  **プレイヤーの操作**: 矢印キー（↑↓←→）、画面のスワイプ、または画面下の操作ボタンでプレイヤー（😀）を動かします。
3.  **ゴール**: ゴール（★）までたどり着くとクリアです。タイマーが停止し、クリアタイムが表示されます。
4.  **新しい迷路**: 「あたらしいめいろ」ボタンを押すと、新しい迷路で再度挑戦できます。
